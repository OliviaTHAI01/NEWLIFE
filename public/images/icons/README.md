# Icons Folder

โฟลเดอร์นี้ใช้สำหรับเก็บรูปภาพไอคอนสำหรับการ์ดต่างๆ

## รูปภาพที่ต้องการ:

1. **lfm.png** - ไอคอนสำหรับ LFM (Illegal Faction Management)
2. **lspd.png** - ไอคอนสำหรับ LSPD (Los Santos Police Department)
3. **lssd.png** - ไอคอนสำหรับ LSSD (Los Santos Sheriff's Department)
4. **lsfd.png** - ไอคอนสำหรับ LSFD (Los Santos Fire Department)
5. **lsmc.png** - ไอคอนสำหรับ LSMC (Los Santos Medical Center)

## ข้อกำหนด:

- รูปภาพควรเป็นไฟล์ PNG
- ขนาดแนะนำ: 64x64 pixels หรือมากกว่า
- พื้นหลังโปร่งใส (transparent background) จะดีที่สุด
- ถ้าไม่มีรูปภาพ ระบบจะแสดง emoji แทนอัตโนมัติ

## วิธีใช้งาน:

1. เพิ่มรูปภาพลงในโฟลเดอร์นี้
2. ตั้งชื่อไฟล์ตามที่ระบุไว้ด้านบน
3. รูปภาพจะถูกโหลดอัตโนมัติในหน้าเว็บ
