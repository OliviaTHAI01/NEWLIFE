🚀 Next.js Discord Login

เว็บแอปพลิเคชัน Next.js พร้อมระบบ Login ด้วย Discord OAuth

หมายเหตุ: Next.js ใช้โครงสร้าง App Router ซึ่งไม่ต้องการไฟล์ index.html แบบดั้งเดิม
หน้าแรกของแอปพลิเคชันอยู่ที่ app/page.tsx
ไปที่แอปพลิเคชัน

📋 วิธีเริ่มใช้งาน:

  1. ติดตั้ง dependencies: npm install
  2. สร้างไฟล์ .env.local และเพิ่ม Discord OAuth credentials
  3. รันแอปพลิเคชัน: npm run dev
  4. เปิดเบราว์เซอร์ไปที่ http://localhost:3000
